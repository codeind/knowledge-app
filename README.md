# Knowledge — news with the background

A knowledge app with two sections:

- **News**: news cards. Selected stories have a **Go deeper** button that opens the backstory (a dated timeline of earlier events), key players, explainers of the ideas involved, every side of a debate, and books (public-domain books first; newer books only as title links).
- **Learn**: short lessons on history, ancient history, economics, sports, and laws (US and India: past, new and upcoming).

Cards are generated by a language model **only from stored source passages**; a second model call checks each claim against those passages, and cards below the quality bar are rejected instead of published.

```
sources ──> passages ──> LLM drafts cards ──> LLM verifies each claim ──> publish / reject ──> link (Go deeper)
(Wikipedia, Gutenberg,       (JSON via tool call,     (supported / partial /                 (stories, players,
 gov news feeds, laws)        cites passage ids)       unsupported)                            explainers, books)
```

## Architecture (cloud)

| Part | Service | What it does |
| --- | --- | --- |
| Website + API | Render (free web service) | FastAPI serves the API and the pre-built website from one URL |
| Database | Neon (free Postgres) | Cards, sources, claims, links, books |
| Daily content job | GitHub Actions (scheduled) | Fetches sources, generates and checks cards, rebuilds links |

Locally the same code runs on a SQLite file with no setup.

## Project layout

```
backend/
  kb/
    schema.sql / schema_pg.sql   tables for SQLite / Postgres
    db.py             database layer (SQLite locally, Postgres when DATABASE_URL is set)
    llm.py            drafting + verification (forced tool calls); offline fallback writer
    sources/          fetchers: wikipedia, books (Gutendex + Open Library), news (RSS), laws (US + India)
    pipeline.py       jobs: daily, news, learn, laws, books; publish/reject rules
    linking.py        story threads + Go deeper links (TF-IDF similarity + shared entities)
    seed_data.json    sample cards so the app is never empty
    api.py            FastAPI app (also serves backend/site)
    cli.py            command line
  site/               pre-built website (output of web/)
  tests/              tests (SQLite always; Postgres when TEST_DATABASE_URL is set)
web/                  Next.js + Tailwind source for the website
.github/workflows/    daily content job + tests
render.yaml           Render deployment
```

## Run locally

Needs Python 3.10+. Node 20+ only if you edit the website.

```bash
./start.sh                     # installs, loads sample cards, serves http://localhost:8000
```

With Node installed, `./start.sh` also runs the website with live reload on http://localhost:3000.
After changing `web/`, run `./scripts/build_site.sh` to refresh `backend/site`.

## Generate content

Set `LLM_API_KEY`, `LLM_DRAFT_MODEL` and `LLM_VERIFY_MODEL` in `backend/.env` (locally) or as repository secrets (cloud). Then, from `backend/`:

```bash
python -m kb.cli run daily                    # news + new US rules, then relink (what the schedule runs)
python -m kb.cli run learn --domain economics
python -m kb.cli run laws --country in        # or us (CONGRESS_API_KEY adds bills)
python -m kb.cli run books --topics rockets inflation --excerpt
python -m kb.cli stats                        # quality numbers (also at /quality in the app)
```

## Deploy

1. **Neon**: create a project and copy its connection string (`postgresql://...`).
2. **Render**: New > Blueprint > pick this repo. Set `DATABASE_URL` to the Neon string. The first start creates the tables and loads the sample cards.
3. **GitHub**: Settings > Secrets and variables > Actions > add `DATABASE_URL`, `LLM_API_KEY`, `LLM_DRAFT_MODEL`, `LLM_VERIFY_MODEL`, `KB_USER_AGENT`. The **Daily content** workflow then runs every morning (or run it by hand from the Actions tab).

## Content and copyright rules

- **Wikipedia** (CC BY-SA 4.0): each card credits its article and shows the licence.
- **Books**: text is used only from books Gutendex marks as public domain. Newer books come from Open Library as metadata only and appear as "Title link only".
- **News**: default feeds are US government publishers (public domain). Other outlets must be added as `"licence": "Link only"`; the pipeline then keeps only the headline, a short summary and the link.
- **Laws**: US federal material is public domain. For India the app uses Wikipedia articles on Indian acts; check the reuse terms of official Indian sites before scraping them.
- Law cards carry a "not legal advice" note.
